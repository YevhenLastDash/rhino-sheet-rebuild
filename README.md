# rhino-sheet-rebuild
Modern rebuild of Rhino Sheet sales tracking system this is a rebuild for portfolio and learning project 

## Roles 
Manager 
Employee

## Core Features 
Log in (Manager/employee)
Employee: submit a sale/service + feedback on the product 
Managere: view all entries set questions to ask employees about the product or service
Database Storage

## Tech Stack 
Frontend: HTML, CSS, JavaScript 
Backend: Node.js+Express 
Database: MongoDB
